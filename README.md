# 🌐 ResourceIQ

> Discover resources. Explore fields. Learn smarter.

🔗 **Live Demo:** https://resource01.netlify.app/

---

## 📌 About

**ResourceIQ** is a resource discovery platform that organizes useful digital resources across different sectors and fields.

Instead of searching through scattered websites and tools, users can explore resources through structured sectors and categories such as:

- STEM
- Technology
- Social
- Lifestyle
- Creative & Humanities

Within each sector, resources are further organized into specific fields, making it easier to discover tools and learning resources relevant to a particular interest.

---

## ✨ Features

### 🌍 Sector-Based Resource Discovery

Resources are organized into major sectors, allowing users to navigate directly to the area they are interested in.

### 🎨 Field-Based Categories

Resources within a sector are divided into focused fields.

For example, the **Creative & Humanities** sector includes:

- Design
- Writing
- Music
- Photography
- Film
- Visual Art
- Architecture
- Literature

### 🔎 Category Filtering

Users can filter resources by individual fields or view all available resources within a sector.

### 📚 Resource Cards

Each resource is presented through a structured card containing relevant information such as:

- Resource name
- Description
- Category
- Resource type
- Pricing information
- Related tags
- External resource link

### ✅ Verified Resources

Resources are presented with verification-oriented information to help users discover relevant and useful tools.

### 📱 Responsive Interface

The interface is designed to provide a consistent experience across desktop and smaller screen sizes.

### 🎯 Simple Navigation

The platform uses sector and category navigation to reduce the effort required to find relevant resources.
